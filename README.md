# CS 370: Current and Emerging Trends in Computer Science

## Pirate Intelligent Agent

For this project, I developed an intelligent pirate agent for a treasure hunt game. The goal of the agent was to learn how to navigate through a maze, avoid obstacles, and reach the treasure successfully. I was provided with starter code that created the game environment, represented the maze, tracked the agent's experiences, and handled parts of the interaction between the pirate and the environment. I used this existing framework to focus on developing the learning behavior of the intelligent agent.

The main code I created was the deep Q-learning training algorithm used by the pirate agent. I implemented the training process so the agent could move through the maze, receive rewards or penalties based on its actions, store experiences in memory, and learn from those experiences over multiple training episodes. The algorithm used an epsilon-greedy strategy to balance exploration and exploitation. Early in training, the pirate explored different actions more frequently. As training continued, it increasingly relied on what it had already learned. A neural network was used to estimate Q-values and determine which actions were most likely to lead the pirate toward the treasure. After training, the agent was able to use its learned strategy to find a successful path through the environment.

## Connection to Computer Science

Computer scientists use computational methods to solve problems, automate tasks, analyze information, and create systems that can improve how people interact with technology. This project showed me that computer science is not only about writing code that follows predefined instructions. With artificial intelligence, we can create systems that learn from experience and adjust their behavior. Reinforcement learning is especially useful for problems where there may be many possible actions and the best solution is discovered through repeated interaction with an environment.

Throughout this course, I also improved the way I approach problems as a computer scientist. Instead of immediately trying to write a complete solution, I first need to understand the problem, identify the inputs, outputs, constraints, and desired outcome, and then determine which algorithm is appropriate. For the pirate agent, this meant understanding the environment, available actions, reward system, neural network, Q-learning process, and the balance between exploration and exploitation. Testing and observing the agent's performance was also important because an algorithm may run without errors while still producing poor results.

Computer scientists also have ethical responsibilities to both end users and the organizations they work for. AI systems should be designed with attention to safety, privacy, fairness, transparency, and reliability. Developers should understand the limitations of the systems they create instead of assuming that an AI model will always make the correct decision. They should also protect user information, test systems carefully, reduce harmful bias when possible, and clearly communicate how automated decisions are being made. Organizations may want powerful and efficient AI systems, but those goals should not come at the expense of the people who use or are affected by the technology. This course helped me understand that responsible computer science requires considering both how a system works and the impact that system can have on others.
